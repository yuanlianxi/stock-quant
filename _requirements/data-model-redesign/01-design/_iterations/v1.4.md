## 关键变更

8 项关键决策（详见 0006 §v1.4 段落）：

1. **新增 `turtle_session_data` 表**：海龟 session 级特有事实（7 字段），通用表不再被海龟字段污染
2. **新增 `session_event_log` 表**：session 生命周期事件流水（8 个 event_type）
3. **新增 `strategy_event_log` 表**：策略执行引擎事件流水
4. **`trade_sessions` 注释调整**：`entry_basis_price` / `entry_locked_atr` 明确"通用字段，含义由策略决定" + `idx_ts_status_open` 部分索引
5. **`position_units` 注释追加**：海龟字段加注释
6. **新增 §7.5 Session 生命周期与触发源**：6 类触发源 + DB/应用层双层唯一性约束
7. **新增 §7.6 用户操作流程**：4 个完整流程图（建仓/加仓/减仓/全平）
8. **新增 6 个 API**：`POST /session` / `POST /session/{id}/orders` / `POST /session/{id}/close` / `GET /session/{id}/events` / `GET /sessions?status=open`

## 关键决策

- **子策略特有事实独立落库**（`turtle_session_data` 1:1 trade_sessions）
- **Session 生命周期显式化**（6 类触发源 + 双层唯一性）
- **手动 vs 信号并发**：应用层互斥锁（HTTP 423）
- **用户入口分散 3 处**（保持分散，符合"操作组"设计）
- **版本策略**：v1.4 独立版本（保留 v1.3 全部内容），便于回滚
