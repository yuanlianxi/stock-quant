# 海龟交易系统（通达信版）代码详解

> 文件性质：通达信（TDX）期货指标公式 / 交易策略可视化脚本
> 策略原型：理查德·丹尼斯（Richard Dennis）的「海龟交易法则」（Turtle Trading System）
> 版本说明：标题注明为「零报错稳定版」，核心特征是 **只有真正触发加仓时，才显示对应的止损线与 ATR**，未触发的加仓档位不绘制，避免图表上出现误导性的"虚假止损线"。

---

# 三个最关键的设计
开仓瞬间锁定一切：用 REF(...,距开仓天数) 回溯到开仓日，把基准价、初始 ATR、手数全部固定，整轮交易不变（符合原版海龟）。
风险平价定仓位：单次手数 = FLOOR(2000 / (2 × ATR × 乘数))，止损被打掉时亏损≈2000 元，波动大的品种自动开少。
"零报错稳定版"的核心：未触发的加仓档用 DRAWNULL 不画线，避免图上出现误导性的虚假止损线。

## 一、策略整体思路（先看全貌）

这是经典「唐奇安通道突破 + ATR 头寸管理 + 金字塔加仓 + ATR/通道止损」的海龟系统，完整交易闭环如下：

| 环节 | 规则 | 对应代码段 |
|------|------|-----------|
| **开仓** | 价格突破 55 日最高/最低 → 首次建仓 | 【4】【5】 |
| **头寸规模** | 用 ATR 把"单笔最大亏损 2000 元"换算成手数 | 【9】 |
| **加仓（金字塔）** | 每向盈利方向走 0.5×初始ATR，加一次仓，最多加 3 次 | 【10】【11】【12】 |
| **止损** | 入场后按 2×ATR 设止损；每加一档，止损整体上移（跟踪止损） | 【13】 |
| **离场** | 反向突破 20 日通道止盈，或触及止损线 | 【14】 |

一个关键设计点：**整套 ATR、基准价、手数都在"开仓那一刻"被锁定**（用 `REF(...,距开仓天数)` 回溯到开仓日取值），之后加仓、算止损都用这个"初始锁定值"，而不是用每天变化的实时 ATR。这与原版海龟规则一致——保证仓位和风险在一轮交易内是确定的。

## 二、通达信基础函数速查（看代码前先记住）

| 函数 | 含义 |
|------|------|
| `H / L / C` | 当根K线的最高价 / 最低价 / 收盘价 |
| `REF(X, N)` | X 在 N 个周期之前的值（向左回溯 N 根K线） |
| `MA(X, N)` | X 的 N 周期简单移动平均 |
| `HHV(X, N)` | 最近 N 周期内 X 的最高值 |
| `LLV(X, N)` | 最近 N 周期内 X 的最低值 |
| `MAX / MIN / ABS` | 取最大 / 最小 / 绝对值 |
| `FLOOR / CEILING` | 向下取整 / 向上取整（这里用来把价格规整到最小变动价位） |
| `IF(cond, a, b)` | 条件为真取 a，否则取 b |
| `COUNT(X, N)` | 最近 N 周期内 X 为真的次数 |
| `SUM(X, N)` | 最近 N 周期内 X 的累加和 |
| `BARSLAST(X)` | 距离上一次 X 为真，过了多少根K线（当根为真则=0） |
| `BARSCOUNT(C)` | 到目前为止有多少根有效K线（数据总长度） |
| `FILTER(X, N)` | X 为真后的 N 周期内屏蔽后续信号（去重/防连续触发） |
| `DATE` | 日期，通达信里是 `YYMMDD` 形式，需 `+19000000` 还原成 `YYYYMMDD` |
| `MINDIFF` | 合约最小变动价位（tick） |
| `MULTIPLIER` | 合约乘数（每点价值 = 乘数 × tick？这里直接是合约乘数） |
| `DRAWNULL` | 画"空值"，即该点不画线 |
| `:=` | 赋值给中间变量（**不输出**到图表显示） |
| `:` | 赋值并**输出**为一条可显示的指标线 |
| `COLORxxxxxx` | 指定颜色（BGR 顺序，非 RGB） |
| `NODRAW` | 计算但不画线（仅作数值供引用 / 在数据窗口可见） |

> ⚠️ 颜色是 **BGR** 顺序：`COLOR0000FF` = 红，`COLORFF0000` = 蓝，`COLOR00FF00` = 绿，`COLORFF00FF` = 紫/品红，`COL0000FFFF` = 黄等。代码注释里写的"橘色/红色"是作者的主观标注，未必与实际显示完全一致。

## 三、逐段详细解读

### 【1】参数定义

```
开仓周期:=55;        // 唐奇安通道：突破 55 日高/低开仓
离场周期:=20;        // 反向突破 20 日通道止盈离场
ATR计算周期:=20;     // ATR 用 20 周期均值
加仓间隔倍数:=0.5;   // 每 0.5×ATR 加一次仓
止损倍数:=2;         // 止损距离 = 2×ATR
单笔最大亏损:=2000;  // 每笔交易愿意承受的最大亏损（元），用于反推手数
```

这是经典海龟"系统二"的参数（55 入场 / 20 出场）。加仓间隔倍数 0.5 比原版的 0.5N 一致，止损 2×ATR 也与原版相同。

---

### 【2】ATR（真实波幅均值）计算

```
真实波幅:=MAX(MAX(H-L, ABS(H-REF(C,1))), ABS(L-REF(C,1)));
ATR波动率:=MA(真实波幅, ATR计算周期), COLOR0000FF;  // 红色
```

- **真实波幅 TR** = 以下三者取最大值：
  1. 当日最高 − 当日最低（当日振幅）
  2. |当日最高 − 昨日收盘|（向上跳空）
  3. |当日最低 − 昨日收盘|（向下跳空）
- **ATR波动率** = TR 的 20 日简单移动平均。海龟系统里这个 ATR 就是衡量"市场波动一个单位（N值）"的核心，用于算手数、加仓间距、止损距离。

---

### 【3】合约参数

```
最小变动:=MINDIFF;            // tick，比如螺纹钢 1 元/吨
乘数:=MULTIPLIER;             // 合约乘数，比如螺纹钢 10 吨/手
最小波动价:=最小变动*乘数;    // 一个 tick 对应的金额（元/手）
```

读取当前合约的交易规则，用于后面把"价格"换算成"金额"，以及把止损价规整到合法的报价档位。

---

### 【4】动态 55 日高低（仅用于突破判断）

```
今日55高:=REF(HHV(H,开仓周期),1), COLORFF00FF;  // 紫色
今日55低:=REF(LLV(L,开仓周期),1);
```

- `HHV(H,55)` 是含当根的 55 日最高，`REF(...,1)` 回退一根 → 得到**不含今天**的前 55 日最高价。
- 这样做是为了用"昨天之前的通道上轨"来判断"今天是否突破"，避免用今天自己的数据判断今天，造成逻辑自洽（未来函数）问题。

---

### 【5】首次开仓信号

```
多开:=H>今日55高 AND REF(H,1)<今日55高;   // 今天最高突破上轨，且昨天还没突破
空开:=L<今日55低 AND REF(L,1)>今日55低;   // 今天最低跌破下轨，且昨天还没跌破

第一次多开:=FILTER(多开, BARSLAST(多开)=0), COLOR8000FF;
第一次空开:=FILTER(空开, BARSLAST(空开)=0), COLOR40FF00;
```

- `多开 / 空开`：用"今天穿越、昨天还没穿越"来捕捉**第一次穿越通道的那一根K线**，避免在通道外连续多日重复发信号。
- `第一次多开/空开`：再用 `FILTER` 配合 `BARSLAST(...)=0` 做一层去重，确保只标记"本轮突破的第一根"。

> 注：作者注释里说"严格触发加仓才显示止损"，这一层去重是为了保证后续"距开仓"等定位准确。

---

### 【6】定位首次开仓的距离

```
距多开:=BARSLAST(第一次多开);  // 距离上一次多头开仓过了几根K线
距空开:=BARSLAST(第一次空开);  // 距离上一次空头开仓过了几根K线
```

这两个值是**整套回溯的关键坐标**。比如 `距多开=3` 表示 3 根K线之前发生过一次多头开仓。后面所有"开仓时锁定的值"都靠它来 `REF` 回去取。

---

### 【7】锁定开仓瞬间的基准价、初始 ATR、开仓日期

```
固定55高_开仓时:=REF(HHV(H,开仓周期), 距多开+1), COLORFF00FF;
固定55低_开仓时:=REF(LLV(L,开仓周期), 距空开+1);
初始锁定ATR:=IF(距多开<距空开, REF(ATR波动率,距多开), REF(ATR波动率,距空开)), COLOR00FFFF;  // 青色
开仓8位日期:=IF(距多开<距空开, REF(DATE+19000000,距多开), REF(DATE+19000000,距空开)), COLORFFFF00; // 黄色
```

- **固定55高/低_开仓时**：把通道值回溯到开仓日并锁定（`距开仓+1` 是为了取到突破当天判断所用的那条通道上/下轨）。这就是后续加仓、止损的**基准价**。
- **初始锁定ATR**：哪个方向开仓更近（`距多开<距空开` 说明最近一次是多头），就取那一天的 ATR 作为本轮固定 N 值。**整轮交易只用这一个 ATR**。
- **开仓8位日期**：把开仓那天的日期还原成 `YYYYMMDD`，方便人工核对是哪天开的仓。

---

### 【8】持仓方向判断

```
持多:=距多开<距空开 AND COUNT(第一次多开, BARSCOUNT(C))>0;
持空:=距空开<距多开 AND COUNT(第一次空开, BARSCOUNT(C))>0;
持仓方向文字:=IF(持多,'多头','空头');
初始基准价:=IF(持多, 固定55高_开仓时, 固定55低_开仓时), COLOR00FFFF, NODRAW;
```

- **持多/持空**：比较"距多开"和"距空开"哪个更近，更近的方向就是当前持仓方向；同时 `COUNT(...)>0` 确保历史上确实出现过该方向的开仓信号。
- **初始基准价**：多头取通道上轨、空头取通道下轨作为加仓/止损的起算点（`NODRAW` 表示只算不画）。

---

### 【9】手数计算（头寸规模 / 风险平价）

```
每手风险: 初始锁定ATR*乘数, COLORFFFF00, NODRAW;              // 黄色
单次手数: FLOOR(单笔最大亏损/(止损倍数*每手风险)), COLORFF00FF, NODRAW;  // 紫色
```

这是海龟系统的灵魂——**用波动率决定仓位**：

- **每手风险** = 初始ATR × 合约乘数 → 价格波动一个 ATR，每手盈亏多少钱。
- **单次手数** = 单笔最大亏损 ÷ (止损倍数 × 每手风险)
  = `2000 / (2 × ATR × 乘数)`
  含义：止损被打掉（价格走 2×ATR）时，亏损刚好≈2000 元。`FLOOR` 向下取整保证不超额。

> 这就是"风险平价"：波动大的品种自动开少，波动小的品种自动开多，使每笔交易承担的金额风险相同。

---

### 【10】加仓价格（基于固定初始 ATR × 0.5）

```
加1价:=初始基准价 + IF(持多,1,-1)*初始锁定ATR*加仓间隔倍数;
加2价:=初始基准价 + IF(持多,2,-1)*初始锁定ATR*加仓间隔倍数;
加3价:=初始基准价 + IF(持多,3,-1)*初始锁定ATR*加仓间隔倍数;
```

- 多头：每向上 0.5×ATR 设一个加仓价 → 加1价 = 基准 +0.5N，加2价 = 基准 +1.0N，加3价 = 基准 +1.5N。
- **空头这里有一个写法问题**：`IF(持多,1,-1)`、`IF(持多,2,-1)`、`IF(持多,3,-1)` —— 空头时三档系数全是 **-1**，导致空头的加2价、加3价与加1价相同（都只下移 0.5N），**没有形成 -0.5N / -1.0N / -1.5N 的阶梯**。

> ⚠️ **潜在 Bug（提请注意）**：空头加仓档位系数应为 `IF(持多,2,-2)`、`IF(持多,3,-3)`。当前代码空头加仓价不正确，多头逻辑则正常。

---

### 【11】加仓信号

```
加1_原始:=IF(持多, H>加1价 AND REF(H,1)<加1价, L<加1价 AND REF(L,1)>加1价);
加2_原始:=IF(持多, H>加2价 AND REF(H,1)<加2价, L<加2价 AND REF(L,1)>加2价);
加3_原始:=IF(持多, H>加3价 AND REF(H,1)<加3价, L<加3价 AND REF(L,1)>加3价);

加1_有效:=FILTER(加1_原始,1);
加2_有效:=FILTER(加2_原始,1);
加3_有效:=FILTER(加3_原始,1);
```

- `加X_原始`：和开仓逻辑一样，用"今天穿越、昨天未穿越"判断价格首次到达各加仓价。
- `FILTER(...,1)`：屏蔽窗口为 1，做最小程度去重（防止同一根重复计数）。

---

### 【12】加仓计数与总持仓

```
加仓总数:=SUM(加1_有效,距多开+1)+SUM(加2_有效,距多开+1)+SUM(加3_有效,距多开+1);
实际加仓次数:=MIN(加仓总数,3);
总持仓:=单次手数*(1+实际加仓次数), COLORFFFF80;
开仓信号值: 第一次多开+加1_有效+加2_有效+加3_有效, COLORFF00FF, NODRAW;
```

- **加仓总数**：在"开仓至今"这个窗口（`距多开+1` 根）内，把三档加仓信号各自出现的次数加总。
- **实际加仓次数**：上限封顶为 3（海龟规则最多加到 4 个单位，即首仓 + 3 次加仓）。
- **总持仓** = 单次手数 ×（1 + 实际加仓次数），最多 = 单次手数 × 4。
- **开仓信号值**：把首仓与三档加仓信号叠加成一个标记序列，方便观察建仓节奏。

> 注：窗口用了 `距多开+1`，多头是对的；空头本应用 `距空开+1`。这是另一处多空不对称、偏向多头的写法。

---

### 【13】止损与 ATR（仅在触发加仓后才计算/显示）

这是本版本的核心改进——**未触发的加仓档不画止损线**，用 `DRAWNULL` 实现。

#### 13.1 各加仓档"当日 ATR + 止损价"

以加 1 档为例（加 2、加 3 同理）：

```
加1当日ATR:=IF(BARSLAST(加1_有效)>=0, REF(ATR波动率, BARSLAST(加1_有效)), 0);
加1止损价:=加1价 - IF(持多,1,-1)*加1当日ATR*止损倍数;
加1止损规整:=IF(BARSLAST(加1_有效)>=0,
              IF(持多, FLOOR(加1止损价/最小变动)*最小变动,
                       CEILING(加1止损价/最小变动)*最小变动),
              DRAWNULL);
动损1:=加1止损规整, COLOR4080FF, NODRAW;
```

- `BARSLAST(加1_有效)>=0`：只有"曾经触发过加 1"才进入计算，否则返回 `DRAWNULL`（不画）。
- **加1当日ATR**：取"加 1 触发那一天"的 ATR（注意这里用的是触发当日 ATR，**不是**初始锁定 ATR）。
- **加1止损价** = 加1价 − 方向 × ATR × 2（多头止损在下方，空头止损在上方）。
- **加X止损规整**：把止损价对齐到合约最小变动价位——多头向下取整（`FLOOR`，止损更保守一点），空头向上取整（`CEILING`）。

> 这里有两套止损体系，区别在于"用哪个 ATR"：
> - **加X止损规整（动损1/2/3）**：用**触发当日的实时 ATR**（`加X当日ATR`）。
> - **一/二/三档止损规整**：用**开仓时锁定的初始 ATR**（见下）。

#### 13.2 初始止损（首仓的止损）

```
初始止损原值:=初始基准价 - IF(持多,1,-1)*初始锁定ATR*止损倍数;
初始止损规整: IF(持多, FLOOR(...)*最小变动, CEILING(...)*最小变动), COLOR40FF00, NODRAW; // 绿
初损:=初始止损规整, COLOR00FF80, NODRAW;
```

首仓的止损 = 基准价 ∓ 2×初始ATR，规整到 tick。绿色显示。

#### 13.3 "原版"档位止损（用初始锁定 ATR，更贴近原版海龟）

```
一档损价:=加1价 - IF(持多,1,-1)*初始锁定ATR*止损倍数;   // 用初始ATR
一档止损规整:=IF(BARSLAST(加1_有效)>=0, ...规整..., DRAWNULL);  // 橘色
二档损价:=加2价 - IF(持多,1,-1)*初始锁定ATR*止损倍数;        // 红色
二档止损规整:=...
三档损价:=加3价 - IF(持多,1,-1)*初始锁定ATR*止损倍数;        // 紫色
三档止损规整:=...
```

与 13.1 的区别：这里全部用 **初始锁定ATR**（开仓时固定的 N），而 13.1 用的是各加仓日的实时 ATR。

#### 13.4 两条最终止损线

```
跟踪止损价: IF(实际加仓次数=3, 加3止损规整,
            IF(实际加仓次数=2, 加2止损规整,
            IF(实际加仓次数=1, 加1止损规整, 初始止损规整))), COLOR00FFFF, NODRAW; // 青色

原版止损价: IF(实际加仓次数=3, 三档止损规整,
            IF(实际加仓次数=2, 二档止损规整,
            IF(实际加仓次数=1, 一档止损规整, 初始止损规整))), COLORFFFF00, NODRAW; // 黄色
```

- **跟踪止损价（青色）**：随加仓档数上移，止损用的是"加仓当日实时 ATR"那套。
- **原版止损价（黄色）**：同样随加仓档数上移，但止损用的是"开仓固定 ATR"那套——这一条更接近原版海龟"所有仓位的止损统一上移到最新加仓价 −2N"的做法。
- 没有任何加仓时（实际加仓次数=0），两者都退化为 `初始止损规整`。

> 核心思想：**每加一次仓，整组持仓的止损就整体上移一档**，把已有浮盈锁住，这就是金字塔加仓配套的"移动止损"。

### 【14】退出条件 + 止盈

```
离场高:=HHV(H,离场周期);    // 20 日最高
离场低:=LLV(L,离场周期);    // 20 日最低
止盈退出多:=L<离场低 AND REF(L,1)>离场低, COLORFF0000;       // 多头：跌破20日低 → 止盈离场
止盈退出空:=H>离场高 AND REF(H,1)<离场高;                    // 空头：升破20日高 → 止盈离场
止盈价格:=IF(持多, 离场低, 离场高);

多损:=L<跟踪止损价 AND REF(L,1)>跟踪止损价, COLOR40FF00;     // 触及跟踪止损（多）
空损:=H>跟踪止损价 AND REF(H,1)<跟踪止损价, COLOR40FF00;     // 触及跟踪止损（空）

多损0:=L<原版止损价 AND REF(L,1)>原版止损价, COLOR40FF00;    // 触及原版止损（多）
空损0:=H>原版止损价 AND REF(H,1)>原版止损价, COLOR40FF00;    // 触及原版止损（空）

止损总信号:=IF(持多, 多损, 空损), COLOR40FF00;
海龟原损:=IF(持多, 多损0, 空损0), COLOR40FF00;
退出信号:=止损总信号 OR 海龟原损 OR 止盈退出多 OR 止盈退出空;
```

- **止盈退出**：经典海龟系统二出场——多头跌破 20 日通道下轨离场，空头升破 20 日通道上轨离场。
- **止损退出**：价格穿越跟踪止损线（或原版止损线）即触发。
- **退出信号** = 任一止损 OR 任一止盈触发，即平掉全部仓位。

## 四、一轮完整交易示例（多头）

假设螺纹钢，开仓日 ATR=40，乘数=10，tick=1：

1. **开仓**：价格突破 55 日高 = 3500，建仓。
   - 每手风险 = 40 × 10 = 400 元/手
   - 单次手数 = FLOOR(2000 / (2 × 400)) = FLOOR(2.5) = **2 手**
   - 初始止损 = 3500 − 2×40 = **3420**
2. **加 1**：价格涨到 3500 + 0.5×40 = **3520** → 再加 2 手（共 4 手），止损上移到 3520 − 2×40 = 3440
3. **加 2**：涨到 3500 + 1.0×40 = **3540** → 再加 2 手（共 6 手），止损上移到 3460
4. **加 3**：涨到 3500 + 1.5×40 = **3560** → 再加 2 手（共 8 手），止损上移到 3480
5. **离场**：价格回落跌破 3480（止损）或跌破 20 日通道下轨（止盈）→ 全部平仓。

## 五、需要注意的几个问题（代码审查意见）

1. **空头加仓价 Bug（重点）**：【10】中 `加2价 / 加3价` 对空头用了 `IF(持多,2,-1)`、`IF(持多,3,-1)`，空头三档系数都是 −1，导致空头加 2、加 3 价格与加 1 相同，加仓阶梯失效。建议改为：
   ```
   加2价:=初始基准价+IF(持多,2,-2)*初始锁定ATR*加仓间隔倍数;
   加3价:=初始基准价+IF(持多,3,-3)*初始锁定ATR*加仓间隔倍数;
   ```
2. **加仓计数窗口偏多头**：【12】里 `SUM(..., 距多开+1)` 对空头应该用 `距空开+1`；可统一为 `IF(持多,距多开,距空开)+1`。
3. **两套止损并存**：跟踪止损（实时 ATR）与原版止损（初始 ATR）同时存在，实盘需明确**只用其中一条**作为真正的离场依据，否则信号会冲突/重复。
4. **`空损0` 表达式疑似笔误**：`H>原版止损价 AND REF(H,1)>原版止损价` 两个条件都是 `>`，无法表达"由下向上穿越"，应为 `REF(H,1)<原版止损价`。
5. **颜色注释与实际显示**：通达信用 BGR 顺序，源码注释里"橘色/红色/紫色"是作者口头标注，渲染颜色以 `COLORxxxxxx` 实际值为准。
6. **均为信号可视化、非自动下单**：本脚本是"指标/选股+画线"用途，只在图上标记开仓、加仓、止损、止盈位置，**不会自动交易**；实盘下单仍需人工或外接程序执行。
